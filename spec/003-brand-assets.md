# 003 — Wordmark, favicon and social preview

**Status:** Accepted
**Owner:** Irina / Silverina

## 1. Context

[001](./001-homepage.md) shipped a homepage shell and deliberately left three brand assets as placeholders:

| Asset | Today |
| --- | --- |
| Wordmark | `SILVERINA` as plain uppercase Geist text in the header and footer |
| Favicon | a temporary `S` in Georgia (a system font, so it differs per device) on a dark square |
| Social preview | none: `twitter:card` is `summary`, there is no `og:image` |

This spec replaces them with one consistent identity. The three assets are done together because the favicon and the preview image are both derived from the wordmark decision.

## 2. Goals

- The name reads as a deliberate mark, not as a navigation label.
- The browser tab icon and the link preview are recognisably the same identity as the page.
- A link to `silverina.dev` pasted into LinkedIn, Telegram, Slack, WhatsApp, iMessage or X shows a designed card.
- No new runtime dependencies and no visible change to performance budgets.

## 3. Design constraints

Everything in section 4 of [001](./001-homepage.md) still applies: quiet, editorial, restrained; paper, ink and silver; no gradients, no decoration, no additional accent colour.

The identity is **typographic**. There is no symbol, mascot or illustration. The only two typefaces are the ones already on the site: Instrument Serif and Geist.

## 4. Wordmark

### 4.1 Process

The wordmark is a design decision that belongs to the owner, so it is not guessed in code. Slice 1 produces a comparison page with the candidates below, each shown at header size, at footer size and as a favicon crop, on the real page background. Each candidate is shown at more than one header size. The owner picks a candidate and a size; the choice is recorded in section 10 before slice 2 starts.

### 4.2 Candidates

| # | Candidate | Idea |
| --- | --- | --- |
| A | `Silverina` — Instrument Serif, regular, title case | carries the hero's serif into the mark; warm, editorial |
| B | `Silverina` — Instrument Serif, italic | the most distinctive; a signature rather than a label |
| C | `SILVERINA` — Instrument Serif, uppercase, tracked | echoes the hero heading directly |
| D | `SILVERINA` — Geist, uppercase, tracked (current), with refined weight and spacing | the quietest; lets the hero own the serif |

No custom letterforms and no ligature tricks in this spec. If none of the four works, the spec returns to `Draft` rather than growing a fifth option in code.

### 4.3 Implementation

- The wordmark is **live text** in the chosen typeface, not an image: it stays selectable, scales with the layout and needs no extra request. Markup keeps natural casing; uppercase, if chosen, comes from CSS.
- It is one `Wordmark` component used by the header and the footer.
- In the header it remains a link to the top of the page with the accessible name `Silverina`.
- If the italic is chosen, the italic `woff2` (Latin only) is added to `fonts.css`. It is not preloaded unless it is above the fold.

## 5. Favicon

- The mark is the letter **S** from the chosen wordmark typeface, converted to **vector outlines**, so it renders identically on every device and does not depend on installed fonts.
- Light `S` (`#F4F1EB`) on a dark rounded square (`#1D1D1B`): legible on both light and dark browser tabs.
- The glyph is optically centred and sized to stay recognisable at 16px.

| File | Size | Used by |
| --- | --- | --- |
| `favicon.svg` | vector | modern browsers |
| `favicon.ico` | 32×32 | legacy fallback, requests to `/favicon.ico` |
| `apple-touch-icon.png` | 180×180, no transparency, no rounded corners (iOS rounds them) | iOS home screen |

- Outlines are produced by a one-off script from the font file already in `node_modules`; the resulting files are committed to `public/`. Instrument Serif is under the SIL Open Font License, which permits this.
- No web app manifest and no further icon sizes: the site is not an installable app.

## 6. Social preview image

- One image, **1200×630px**, PNG, at most **300 kB**, at `https://silverina.dev/og.png`.
- Composition follows the hero: paper background, `FRONTEND` / `DEVELOPER` in Instrument Serif with the second line pushed to the far edge, the wordmark, and `silverina.dev`.
- Important content stays inside a centred 1200×600 safe area with at least 60px padding; some platforms crop the edges.
- No tagline or other copy.
- Text is large enough to read in a thumbnail-sized card. No photo, no screenshot, no gradient.

### 6.1 Generation

- The image is rendered from an HTML template with the site's own fonts and tokens, using Playwright (already a dev dependency), by `npm run generate:og`.
- The PNG is committed to `public/`. It is regenerated by hand when the design changes, not on every build, so builds stay fast and deterministic.

### 6.2 Metadata

```html
<meta property="og:image" content="https://silverina.dev/og.png" />
<meta property="og:image:width" content="1200" />
<meta property="og:image:height" content="630" />
<meta property="og:image:alt" content="Silverina — Frontend Developer" />
<meta name="twitter:card" content="summary_large_image" />
```

Image URLs are absolute: crawlers do not resolve relative ones reliably.

## 8. Out of scope

Brand guidelines document, a symbol or monogram beyond the favicon `S`, custom lettering, animated logo, dark mode, per-page preview images, web app manifest, business-card or print assets, redesign of anything else on the page.

## 9. Acceptance criteria

### Wordmark

- [ ] The owner's choice is recorded in section 10.
- [ ] Header and footer render the same `Wordmark` component.
- [ ] The header link's accessible name is `Silverina` and it still scrolls to the top.
- [ ] No horizontal overflow at 320px with the three navigation links.

### Favicon

- [ ] `favicon.svg` contains outlines only: no `<text>`, no font reference.
- [ ] The icon is legible at 16px on light and dark tab backgrounds.
- [ ] `/favicon.ico` and `/apple-touch-icon.png` respond with 200 on the deployed site.

### Social preview

- [ ] `og.png` is 1200×630 and at most 300 kB.
- [ ] `npm run generate:og` reproduces it.
- [ ] The card renders in LinkedIn Post Inspector and in a Telegram message (checked by the owner; both need a public URL and an account).

### Quality gates

- [ ] All gates from [002](./002-ci-quality-gates.md) pass; the JavaScript bundle stays within 80 kB.
- [ ] A browser check asserts that every icon and the `og:image` URL referenced in `<head>` resolves.
- [ ] Lighthouse mobile stays at or above 95 in all four categories, CLS below 0.05.
